# 元数据说明

`official-class-names.txt` 是 2026-08-08 从作者 GitHub 所指向的百度网盘公开分享根目录只读枚举得到的 203 个唯一类别目录名，并按 Unicode 码点排序。

这些名称是发布版本标识，不等于经过分类学规范化的学名。文件没有 class ID；训练前应显式生成并固化映射。不要依赖操作系统或框架临时返回的目录顺序。
