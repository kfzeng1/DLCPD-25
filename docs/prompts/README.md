# AI 工程师提示词

本目录保存三位 AI 工程师的固定启动提示词。每次新建会话、切换模型或恢复长期任务时，先发送对应提示词；工程师完成预备检查并报告“已就绪”后，再单独发送阶段任务。

| 文件 | 角色 | 阶段 |
|---|---|---|
| `data-engineer.md` | AI 数据工程师 | D0-D5 |
| `algorithm-engineer.md` | AI 算法工程师 | A0-A5 |
| `application-engineer.md` | AI 应用工程师 | P0-P4 |

提示词只用于恢复上下文，不代表授权执行任务。用户必须明确给出阶段 ID；没有阶段 ID 时，工程师只能阅读和汇报预备状态，不能修改文件。

工程师开始工作前应读取自己的 `docs/worklogs/*.md`，完成工作后追加记录。工程师无权修改其他角色日志、总负责人日志或 `docs/acceptance-checklist.md`。
