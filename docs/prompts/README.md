# 三位工程师启动提示词

三个提示词用于让独立 AI 工程师快速进入双数据集联合训练的预备状态。提示词只授权阅读和检查；用户或总负责人随后明确下达一个活动阶段。

每位工程师还必须阅读 `../workplans/` 中自己的工作单。阶段状态只以 `../acceptance-checklist.md` 为准，工作完成后记录到自己的 `../worklogs/`，不得另建平行计划。

| 文件 | 角色 | 负责阶段 |
|---|---|---|
| `data-engineer.md` | 数据工程师 | T0 已完成，仅维护 |
| `algorithm-engineer.md` | 算法工程师 | J1-J4 |
| `application-engineer.md` | 应用工程师 | J5 |
