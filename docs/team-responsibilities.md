# 三位 AI 工程师职责

## 总负责人

总负责人维护阶段、接口、验收状态和 Git 边界，逐阶段派工、复验、提交和总结。工程师不得自行进入下一阶段、提交或推送。最终只接受一个联合 checkpoint 和一次共享主干前向的实现。

## 数据工程师

T0 已通过，当前进入维护状态。负责：

- 维护 DLCPD-25 冻结分类合同和 IP102 T0 检测合同；
- 必要时修复 Dataset、split verifier 和数据测试；
- 保证联合训练分别读取固定 DLCPD-25 train/val 和 IP102 train/val；
- 保持 IP102 的源标签、内部 `1-96` 和 DLCPD-25 `0-202` 三套编号可追溯。

禁止重分 split、修改原图/XML、taxonomy、映射或使用 test 参与训练选择。没有数据合同问题时不重跑耗时全量数据工程。

## 算法工程师

负责 J1-J4，所有权为联合模型、分类/检测预处理、训练与评估代码、配置、算法测试及训练/发布 artifacts。

- J1：从历史分类 `best.pt` 初始化，用 DLCPD-25 train/val 适配统一 224 直缩预处理，冻结分类初始化 checkpoint。
- J2：实现一次共享主干前向和双 DataLoader 交替训练；完成小样本过拟合、梯度边界、AMP、显存和 checkpoint 冒烟。
- J3：按 `1:1` step 比例完整联合训练；只用分类 val 与检测 val 选模型，控制分类遗忘。
- J4：冻结模型与后处理后，各执行一次分类 test 和检测 test，生成唯一联合模型包。

算法工程师必须证明：分类 step 不更新检测头，检测 step 不更新分类头，两种 step 都按较小学习率更新同一个共享主干；联合推理只运行一次主干。

禁止部署两份权重、双输入或两次主干前向；禁止改回 640 输入；禁止把历史 `88.5517%` 直接写成新联合模型指标；禁止用任一 test 调参。

## 应用工程师

负责 J5，所有权为 `inference/`、`web/`、应用配置、应用测试和运行文档。

- 只加载 J4 的一个联合模型包；
- 一次图片解码、一次统一 224 预处理、一次联合推理；
- 展示 203 类分类 Top-5、低置信提示，以及 96 类害虫检测框；
- 将 224 检测坐标正确映射回原图；
- 处理无框、多框、损坏图、超大图和 CPU/CUDA 回退；
- 页面明确检测不覆盖无框标注的病害、健康和缺陷。

禁止回退为历史分类模型加单独检测模型，禁止修改训练参数、权重、映射或 split。

```text
DLCPD-25分类合同 ──┐
历史分类权重 ──────┼-> J1 -> J2 -> J3 -> J4 -> J5 -> F1

```

工程师只记录阶段、修改文件、命令、测试、指标、遗留问题和下一阶段许可，不粘贴长控制台输出。
