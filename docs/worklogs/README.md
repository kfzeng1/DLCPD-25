# 工作日志规则

工作日志用于跨会话保存必要上下文，不保存完整命令输出、CSV、图片或模型权重。

| 文件 | 维护者 | 当前范围 |
|---|---|---|
| `data-engineer.md` | 数据工程师 | D0-D5 历史与维护记录 |
| `algorithm-engineer.md` | 算法工程师 | A1-A3；保留旧 A0 历史 |
| `application-engineer.md` | 应用工程师 | P1-P2 |
| `project-lead.md` | 总负责人 | 验收和项目决策 |

工程师只追加自己的日志，不修改验收清单。每个阶段完成后追加：

```text
阶段：
修改文件：
运行命令：
测试结果：
关键指标：
遗留问题：
是否进入下一阶段：否
```

退回后继续修复同一阶段，无需建立新修订编号或长篇复验记录。总负责人只在里程碑通过时更新 `acceptance-checklist.md` 和提交 Git。
