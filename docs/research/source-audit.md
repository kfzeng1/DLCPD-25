## 类别目录问题

云端 203 个物理目录中保留了原发布命名，包括全角括号、大小写不一致、`citru`、`mossaic`、`syndrone`、`Redding`、`Polyphagotars onemus` 等疑似缩写或拼写问题。本地目录已经追加中文译名，因此通过显式别名表维持与官方版本的对应关系：

- 把官方原目录名保存为 `source_class_name`，把当前目录名保存为 `local_directory_name`；
- 规范名、学名、宿主作物和中文名另建字段并保留证据来源；
- 未经植保或昆虫分类专家复核，不把机器翻译当作权威标签；
- 不再执行第二轮目录重命名；旧脚本只保留为历史记录且默认预览。

## 许可与可重复性风险

论文文本采用 CC BY 4.0，但作者数据仓库没有数据许可证。论文称在线部分整合 PlantVillage、IP102 和 New Plant Diseases Dataset 等来源，却没有公开逐图来源、许可继承关系或 source manifest。因此“公开可下载”不等于“可任意再分发或商业使用”。

论文也未在公开仓库提供以下复现实验所需材料：逐图清单、训练/测试 split、固定种子具体值、清洗阈值、类别 ID 映射、训练代码和预训练权重。使用者应为自己的本地子集生成 manifest、内容哈希、类别映射和 split，并避免声称逐项复现论文结果。
