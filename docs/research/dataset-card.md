## 建设过程（论文陈述）

论文称数据经过在线数据收集、田间采集、质量清洗、专家与志愿者复核、分类体系建立、初分、增强和划分等阶段。在线来源明确提到 PlantVillage、IP102 和 New Plant Diseases Dataset；田间图片来自中国农业大学涿州、曲周和北京通州三个试验站。

论文称在线部分清洗后为 180,143 张、192 类；田间采集最初得到 59,800 张候选，最终保留 41,800 张，并增加 11 个在线部分缺少的类别。`180,143 + 41,800 = 221,943`，但文中的百分比和删除比例不能由这些数字复算，见 [来源审计](source-audit.md)。

## 论文基准

论文将 221,943 张图片按固定随机种子近似划分为 177,555 张训练集和 44,388 张测试集，统一缩放到 256 x 256。作者在 DLCPD-25 上进行 MAE、SimCLR v2 和 MoCo v3 自监督预训练，再做线性探测；报告的最好结果为 SimCLR v2 accuracy 72.1%、macro F1 71.3%。

该划分未公开逐图 manifest、随机种子值或重复组隔离规则，因此本地子集不能声称严格复现论文基准。随机按图片切分也可能让在线数据中的近重复图跨集合泄漏。

## 适用任务

- 203 类图像分类和长尾学习；
- 农业领域自监督预训练；
- 层级分类、开放集识别和不确定性估计；
- 经额外对象级标注后，用于病虫害目标检测或分割研究。

## 不适用或需补充标注的任务

- 直接监督训练目标检测器或实例分割器；
- 病害严重度估计、目标计数和病斑面积测量；
- 依赖可靠地理位置、时间、设备或 online/field 来源的研究；
- 在未确认数据许可和原始来源许可前进行再分发或商业发布。

## 本项目版本规则

1. 以 [official-class-names.txt](../../metadata/official-class-names.txt) 为类别完整性基准，通过 [class-directory-aliases.json](../../metadata/class-directory-aliases.json) 兼容当前中文目录名。
2. 当前物理目录不再批量改名；训练时生成带校验和的显式 ID 映射，不把目录排序直接当作长期稳定 ID。
3. 总样本量、每类数量、扩展名和坏图数必须由当前本地数据审计得出。
4. 报告中使用“DLCPD-25 的 203 类、221,396 图像本地子集”，并附审计日期和 manifest 校验和。
5. 中文名、规范学名和别名只放在独立元数据列，不重命名原始目录。
