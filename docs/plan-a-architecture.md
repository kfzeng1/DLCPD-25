# Plan-A 双专家模型架构

## 为什么不再用联合模型

v1 使用一个 ResNet-50 共享主干，分类和 Faster R-CNN 检测都统一输入 224×224。缺点是：

- IP102 平均尺寸约 544×431，224 直缩造成细粒度信息损失和形态失真；
- 分类与检测共享同一分辨率、同一训练节奏，互相妥协；
- 检测 Precision 只有 68.9%，类别误报明显；
- 分类 Macro-F1 只有 75.4%，长尾尾部类别表现差。

Plan-A 把两个任务解耦，分别使用最优骨干、分辨率和采样策略。

## 系统流程

```text
输入图片
  ├─ 分类专家 ConvNeXt-Tiny @384
  │     └─ 203 类 Top-K + 宿主/属性辅助信息
  └─ 检测专家 Faster R-CNN(ConvNeXt-Tiny-FPN) @640 / YOLOv8s @640
        └─ 96 类害虫框
             └─ 映射回 DLCPD-25 class_id 0..202
```

## 分类专家

- 骨干：`ConvNeXt-Tiny`（ImageNet 预训练），备选 `EfficientNetV2-S`。
- 输入：384×384 等比缩放。
- 主头：203 类。
- 辅助头：22 宿主 + 4 标签属性，仅训练时使用，改善细粒度层级混淆。
- 长尾策略：
  - Class-Balanced Focal Loss；
  - 类别平衡采样；
  - Label Smoothing；
  - EMA；
  - 可选 flip TTA。
- 选择指标：val Macro-F1。

## 检测专家

- 骨干：`ConvNeXt-Tiny-FPN`，检测头优先 Faster R-CNN。
- 输入：最长边 640 的 letterbox，禁止非等比 224 直缩。
- 数据特点：
  - 18,976 个正式样本，22,283 个有效框；
  - 约 93% 图片只有一个目标；
  - 中位相对面积约 0.35，属于“大目标 + 细粒度分类”问题。
- 长尾策略：
  - Repeat Factor Sampling；
  - RoI 分类使用 sigmoid + focal loss，而不是 softmax；
  - 单目标场景把最大检测数限制为 30。
- 选择指标：val mAP@0.5:0.95。

## 训练顺序

1. 训练分类专家，冻结配置后在 DLCPD-25 test 评估一次；
2. 训练检测专家，冻结配置后在 IP102 官方 test 评估一次；
3. 两个模型分别导出 ONNX/TorchScript，由 Web 应用编排；
4. 测试集不参与模型选择、阈值选择或调参。

## 基线对比

| 任务 | v1 指标 | Plan-A 目标 |
|---|---|---:|
| 分类 Top-1 | 91.32% | ≥ 93% |
| 分类 Macro-F1 | 75.45% | ≥ 80% |
| 检测 AP50 | 65.53% | ≥ 75% |
| 检测 mAP@0.5:0.95 | 35.88% | ≥ 45% |

目标值不是承诺，只是训练时用来判断新架构是否值得替换旧模型。
