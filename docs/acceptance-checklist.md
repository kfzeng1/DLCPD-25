## 4. 算法阶段

### A0-A1 准入和冒烟

- [ ] 复核 203 类、split 互斥、重复组不跨 split 和 taxonomy hash。
- [ ] 模型输出形状为 `[N, 203]`，loss 和概率均为有限值。
- [ ] checkpoint 能重新加载，CPU 和 CUDA 至少各完成一次前向测试。
- [ ] 32-64 张固定小样本能够明显过拟合；失败时先排查链路。
- [ ] OOM 按 batch 16 -> 8 -> 4 -> 梯度累积的顺序处理并记录。

### A2-A3 训练与对照

- [ ] ResNet-50 和 ConvNeXt-Tiny 都使用 ImageNet 预训练及同一 split。
- [ ] 每个 run 保存解析配置、seed、环境、Git commit、日志和 checkpoint。
- [ ] 普通 CE、weighted CE、采样策略采用单变量对照。
- [ ] 只使用验证集选择方案，报告训练时间和峰值显存。
- [ ] 不因模型名称强行选择 ConvNeXt；验证表现不优时允许发布 ResNet-50。

### A4-A5 冻结与交接

- [ ] 先基于验证集冻结模型和阈值，再执行一次最终测试。
- [ ] 报告 Top-1、Top-5、Macro-F1、Balanced Accuracy 和分层指标。
- [ ] 包含混淆矩阵、至少 30 个错误样例和少样本类别分析。
- [ ] 模型包包含权重、配置、预处理、taxonomy 快照、指标、模型卡和校验和。
- [ ] 同一固定样例重复推理结果稳定，taxonomy hash 不匹配时拒绝加载。
