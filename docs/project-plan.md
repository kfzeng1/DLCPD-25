# DLCPD-25 分类系统项目计划

## 1. 项目目标

在 20 个工作日内交付一个可答辩、可复现的 DLCPD-25 图像分类系统：用户上传一张图片，系统输出宿主作物、四大标签属性、具体病虫害/缺陷类别、置信度和 Top-5 结果。

项目不做目标检测。DLCPD-25 当前只有目录级图像标签，没有边界框、分割掩膜或严重度标注。

## 2. 标签层级

```text
宿主作物（22 个）
└── 标签属性（农业有害生物 / 植物病害 / 健康 / 非生物或生理缺陷）
    └── 具体类别（203 个）
```

训练的最终标签是 203 个具体类别。宿主和四大类从 `metadata/class-taxonomy.json` 读取，用于级联展示、分层评估和错误分析。

## 3. 硬件与模型决策

当前电脑：Intel Core i7-13700H、20 线程、15 GiB RAM、NVIDIA RTX 4070 Laptop，实际可用显存 7.62 GiB。已有 `/home/zkf/pytorch-env`，包含 Python 3.12.3、PyTorch 2.11.0+cu128 和 torchvision 0.26.0+cu128，CUDA 已实测可用。磁盘空间足够保存原图、缓存、模型和实验结果，但不应复制数据集。

主线采用 ImageNet 预训练的 `ConvNeXt-Tiny`，输入 224 x 224，AMP 混合精度，batch size 从 16 开始测试；显存不足时降到 8 或使用梯度累积。`ResNet-50` 作为稳定基线和故障回退。

不把 MAE、SimCLR v2、MoCo v3 作为首要交付：论文级自监督预训练需要更长训练时间和更大计算资源。它们只作为算法工程师在主线完成后的可选实验，优先使用公开预训练权重或在本地小规模抽样验证。

## 6. 风险控制

- 203 类长尾明显：不承诺每一类都达到相同精度；报告必须列出少样本类别。
- 近重复图片会造成虚高指标：先分组再切分，禁止先随机切分。
- 预训练权重下载失败：保留 ResNet-50 权重缓存和离线加载说明。
- 显存不足：优先降低 batch size，再降低输入尺寸，最后采用梯度累积；不随意改变类别映射。
- 低置信度图片不强行给出确定诊断，界面显示“可能不在已知类别内”。
