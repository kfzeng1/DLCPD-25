# 分类与目标检测系统开发计划

## 项目目标

课题名称为“基于DLCPD-25数据集的农产品病虫害与缺陷分类目标检测系统”。系统包含两个有明确数据依据的任务：

1. 使用 DLCPD-25 对整张图片进行 203 类病虫害、健康或缺陷分类；
2. 使用 IP102 的 Pascal VOC 边界框，对其中可映射到 DLCPD-25 的害虫类别进行定位检测。

最终页面接收一张图片，同时显示 203 类整图分类结果和害虫检测框。不得宣称可以定位没有边界框标注的病害或缺陷。

## 已完成基线

- DLCPD-25 `data-v1` 已冻结：203 类、221,377 张可用图片，固定 train/val/test。
- ResNet-50 分类模型已发布：Test Top-1 `88.5517%`，Macro-F1 `71.2177%`。
- 分类 Gradio 应用已完成并可在 `7860` 端口运行。
- IP102 检测数据已下载和解压：18,981 张图片、18,976 个 XML、官方 trainval/test 为 15,178/3,798；正式划分外的 5 张图片不进入训练或评估。
- 97 个 IP102 源标签已映射到 96 个 DLCPD-25 公共类别 ID。
- 共享 ResNet-50 主干、FPN 和 Faster R-CNN 检测头的代码骨架已完成，真实 GPU 损失前向通过。

## 技术架构

```text
输入图片
  -> 共享 ResNet-50 主干
      -> 203 类整图分类头
      -> FPN + RPN + Faster R-CNN 检测头
          -> 96 类害虫框
          -> 推理出口统一转换为 DLCPD-25 class_id 0-202
```

检测头内部使用连续标签 `1-96`，`0` 为背景；这是 Faster R-CNN 的实现约束。应用、指标和模型包对外只使用 DLCPD-25 `class_id 0-202`。详细映射见 `ip102-detection-design.md`。

## 硬件与时间

本机使用 `/home/zkf/pytorch-env`，RTX 4070 Laptop 可用显存约 7.62 GiB。Faster R-CNN 初始建议单卡 batch 2、AMP、梯度累积；先冻结 ResNet-50 主干，只训练 FPN/RPN/ROI 检测分支，稳定后最多解冻 `layer4` 小学习率微调。

项目不重新训练 203 类分类模型，不重新执行 DLCPD-25 的 D2-D4，也不补人工框标注。若完整 96 类检测训练效果受长尾影响，应报告逐类 AP 和低样本限制，不得改成 5 类后仍宣称完成全部类别。
