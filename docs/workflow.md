## 验收规则

- 每次只执行并验收一个阶段；通过后由总负责人提交。
- J1/J3 只用 val 选型；J4 前禁止读取两个正式 test 指标。
- J2 必须验证两个任务的梯度边界、一次共享前向和完整 checkpoint 恢复。
- J3 每次验证同时报告分类和检测，任一任务退化都不得隐藏。
- 退回时修复同一阶段，不创建无必要的 R1/R2 平行版本。
- 除非用户明确要求，否则提交但不推送。
