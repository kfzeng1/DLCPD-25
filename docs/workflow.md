```text

docs/ip102-detection-design.md 和自己的提示词/工作日志。
```

## 验收规则

- 普通阶段运行定向测试与 `git diff --check`；T1、T3、T4、F1 运行全量测试。
- 总负责人复查代码、数据边界、指标和 Git diff，通过后提交。
- 原始数据、冻结分类模型、taxonomy 和正式 test 不得原地修改。
- 官方检测 test 只允许 T3 在冻结后评估一次，不得用于调参。
- 退回时修复同一阶段，不新增繁琐的 R1/R2 编号，除非产物契约确实需要并存。
- 除非用户明确要求，否则只提交、不推送。
