# 双数据集联合模型工作单

按以下顺序调用，前一阶段经总负责人验收并提交后才进入下一阶段：

1. `data-engineer-detection.md`：T0 已完成，数据工程师进入维护状态。
2. `algorithm-engineer-detection.md`：算法工程师依次执行 J1、J2、J3、J4。
3. `application-engineer-detection.md`：应用工程师执行 J5。
4. 总负责人执行 F1，完成联合系统验收、提交和总结。

工作单是执行细则，`../acceptance-checklist.md` 是唯一状态表，`../worklogs/` 只记录已经发生的工作。
