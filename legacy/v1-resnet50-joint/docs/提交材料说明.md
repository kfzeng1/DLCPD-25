# 提交材料说明

本目录按课程大作业要求组织，源代码、实验报告、结果、截图和演示资源均放在 `project/` 下。

| 课程要求 | 对应位置 | 说明 |
|---|---|---|
| 完整实验报告 | `docs/实验报告.md` | 包含背景、原理、模型、公式、实现、过程、结果和展望 |
| 源代码 | `src/` | 数据加载、模型、推理与 Gradio 应用 |
| 配置与依赖 | `configs/`、`pyproject.toml` | 应用配置及安装依赖 |
| 最终模型 | `assets/model/` | 一份联合模型包 |
| 实验结果 | `assets/results/` | 分类、检测与逐类指标 |
| 演示截图 | `docs/screenshots/` | 桌面端与移动端的实际页面截图 |
| 模型架构材料 | `docs/presentation/` | PPTX 和 PDF |
| 演示样例 | `assets/samples/` | 一张害虫图和一张病害图 |
| 数据说明 | `assets/data/README.md` | 数据统计、来源、复现位置和使用边界 |

## 大文件说明

DLCPD-25 原始分类图片约 17 GB，IP102 原始检测图片与 XML 约 884 MB，无法与作业代码重复存放。最终 `joint-best.pt` 约 484 MiB，提交压缩包时应保留 `assets/model/joint-best.pt`。

## 最小运行材料

演示 Web 应用需要 `src/`、`configs/`、`pyproject.toml` 和完整的 `assets/model/`。数据集说明、结果文件和演示图片均已置于本作业目录。
