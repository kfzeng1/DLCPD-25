# 基于 DLCPD-25 数据集的农产品病虫害与缺陷分类目标检测系统

## 摘要

农业生产中的病虫害、病害与非生物胁迫会直接影响作物产量和品质。针对单一分类模型无法给出害虫位置、单一检测模型又无法覆盖病害和生理缺陷的问题，本项目构建了一个联合图像分析系统。系统以 DLCPD-25 的 203 类整图分类数据和 IP102 的害虫边界框数据为监督来源，采用共享 ResNet-50 主干、203 类分类头与 Faster R-CNN 检测分支。模型先在 DLCPD-25 上完成 25 轮 203 类分类训练，再进行统一预处理适配和 10 轮双数据集联合训练。输入图片统一进行 RGB 转换和 `224 x 224` 直缩，一次共享主干前向同时输出细粒度分类 Top-5 与 96 类害虫检测框。

在冻结测试集上，分类 Top-1、Top-5 和 Macro-F1 分别达到 91.3157%、96.4289% 和 75.4451%；检测 mAP@0.5:0.95、AP50、Precision 和 Recall 分别为 35.8823%、65.5326%、68.9095% 和 80.1980%。系统提供 Gradio 页面，支持图片上传、Top-5 查看、检测框可视化和低置信度提示。实验表明，共享主干和双数据集交替训练可在有限显存条件下完成分类与害虫定位的联合任务，但对小目标和无框监督类别仍存在明显限制。

**关键词：** 农产品病虫害；图像分类；目标检测；ResNet-50；Faster R-CNN；DLCPD-25；IP102

## 1. 课题背景与研究意义

病虫害识别是智慧农业中的基础视觉任务。传统人工巡检依赖经验，面对大面积田间图像时效率有限。深度学习分类模型可以判断整张图片所属类别，但不能指出害虫所在区域；目标检测模型能够输出边界框，却需要对象级标注，而多数农业病害数据集只提供图像级标签。

DLCPD-25 提供覆盖害虫、植物病害、健康状态和非生物/生理缺陷的 203 类图像级数据，适合建立细粒度分类能力。IP102 提供昆虫害虫的 VOC 边界框标注，能够补足定位监督。本项目将两者组合：对所有 203 类给出分类结论，并仅对具有 IP102 边界框监督且完成映射的 96 类害虫提供位置框。该设计避免把整图分类标签误当成检测框，也使系统能够真实表达自身能力边界。

## 2. 数据集与任务定义

### 2.1 DLCPD-25 分类数据

DLCPD-25（Dataset of Large-scale Crop Pests and Diseases, 2025）是农业病虫害图像分类数据集。本地版本包含 203 个非空类别目录和 221,396 个原始文件；质量审计后有 221,377 张可用图片。依据内容重复组隔离后的固定划分为 train/val/test `177,021/22,178/22,178`。每张图片只有一个图像级标签，不能直接作为目标检测的边界框监督。

类别采用“宿主作物 -> 四大标签属性 -> 具体类别”的组织方式。四大属性为农业有害生物、植物病害、健康和非生物/生理缺陷。系统最终训练目标仍为 203 个细粒度类别，而层级信息用于页面展示和结果解释。

### 2.2 IP102 检测数据

IP102 是害虫识别数据集，本项目使用其 VOC XML 目标框。正式检测数据包含 18,976 张图片与 22,283 个有效框，固定 train/val/test 为 `12,142/3,036/3,798`。原始标注实际出现 97 个源标签，其中两个源标签映射到同一公共类别，因此检测头最终使用 96 个前景类别，另加背景类。

### 2.3 任务边界

给定一张 RGB 图片，系统输出：

1. DLCPD-25 203 类中的 Top-5 分类结果、宿主和四大属性；
2. 仅对映射到 IP102 边界框标签空间的 96 类害虫输出检测框、类别和置信度；
3. 分类置信度低于 0.55 时提示结果不确定；检测无框时不将其解释为健康。

因此，系统名称中的“目标检测”具体指害虫定位，不应宣称能够定位全部病害、健康或缺陷类别。

## 3. 相关原理

### 3.1 ResNet-50

残差网络通过残差连接缓解深层网络的梯度退化。对第 `l` 个残差块，输出可写为：

```text
y_l = F(x_l, W_l) + x_l
x_{l+1} = ReLU(y_l)
```

其中 `F` 表示卷积、归一化和激活组成的残差映射，`x_l` 为快捷连接输入。ResNet-50 既能提取高层语义特征，也具有成熟的 ImageNet 预训练权重，适合课程项目中的迁移学习。

### 3.2 FPN 与 Faster R-CNN

特征金字塔网络（FPN）将 ResNet 不同深度的特征自顶向下融合，以获得多尺度表示。区域建议网络（RPN）在特征图上产生候选框，ROI Heads 对候选区域进行分类和边界框回归。检测损失由 RPN 与 ROI 两部分组成：

```text
L_det = L_rpn_cls + lambda_1 L_rpn_box + L_roi_cls + lambda_2 L_roi_box
```

分类项通常采用交叉熵，边界框回归采用平滑 L1 损失。FPN 对不同尺度目标更友好，但本项目统一输入 `224 x 224`，小昆虫仍可能在缩放后丢失细节。

### 3.3 分类损失与评价指标

分类头输出 203 维 logits `z`，softmax 概率为：

```text
p_i = exp(z_i) / sum_j exp(z_j)
```

对真实标签 `y`，使用加权交叉熵和标签平滑：

```text
L_cls = - w_y sum_i q_i log(p_i)
q_i = (1 - epsilon) * 1(i = y) + epsilon / C
```

其中 `w_y` 是由类别频率得到并截断的权重，`epsilon` 为标签平滑系数，`C=203`。Top-1 衡量首选类别正确率，Top-5 衡量真实类是否位于前五，Macro-F1 对每类 F1 求平均，能够更敏感地反映长尾类别表现。

检测使用 COCO 风格 mAP@0.5:0.95，即在 IoU 阈值 `0.50, 0.55, ..., 0.95` 上计算 AP 后取平均。预测框与真值框的 IoU 定义为：

```text
IoU(B_p, B_g) = area(B_p intersection B_g) / area(B_p union B_g)
```

### 3.4 交替联合训练

联合训练并非从随机参数开始。模型首先从 ImageNet V2 预训练 ResNet-50 初始化，在 DLCPD-25 的 203 类分类任务上完成 25 轮训练，并在普通交叉熵与类别加权交叉熵对照中选择验证集 Macro-F1 更高的类别加权模型。随后用 5 轮训练将分类模型适配到与检测分支一致的 `224 x 224` 整图直缩预处理，再加入 FPN、RPN 和 ROI Heads 开展联合训练。

共享主干参数记为 `theta_s`，分类头与检测头参数分别为 `theta_c`、`theta_d`。每个训练周期按 `1:1` 交替执行分类 batch 和检测 batch：

```text
classification step: minimize L_cls(theta_s, theta_c), theta_d frozen
detection step:      minimize L_det(theta_s, theta_d), theta_c frozen
```

两种步骤都会更新 `theta_s`，从而使主干同时学习类别判别特征与目标定位特征；任务无关头在对应步骤冻结，避免无标签任务产生无效梯度。

## 4. 系统设计与代码实现

### 4.1 总体结构

```text
输入图片
  -> EXIF 校正、RGB 转换、Bicubic 直缩 224 x 224、ImageNet 归一化
  -> 共享 ResNet-50 主干（一次前向）
      -> 全局池化 + Linear(2048, 203) -> 分类 Top-5
      -> FPN + RPN + ROI Heads        -> 96 类害虫检测框
  -> 分类层级映射、NMS、坐标反算和页面展示
```

分类与检测严格共享同一个输入张量和同一份主干特征。IP102 框随图片同比例缩放到 `224 x 224`，推理时再按原图宽高反算。模型包包含权重、类别 taxonomy、IP102 映射、预处理、后处理、指标和 checksum，加载前逐项验证哈希。

### 4.2 代码模块

| 目录 | 作用 |
|---|---|
| `src/dlcpd25_classifier/data/` | DLCPD-25 分类 Dataset 和固定 split 读取 |
| `src/dlcpd25_classifier/detection/` | IP102 Dataset、类别映射、FPN/Faster R-CNN 与 COCO 评估 |
| `src/dlcpd25_classifier/training/` | 训练与推理共用的图像预处理定义 |
| `src/dlcpd25_classifier/inference/` | 模型包校验、图像处理、联合预测和结果绘制 |
| `src/dlcpd25_classifier/web/` | Gradio 上传页面和结果表格 |
| `configs/` | 应用、训练、评估配置 |
| `tests/` | 回归测试与输入边界测试 |

### 4.3 应用交互

应用启动后加载一份 `joint-best.pt`，用户上传图片即可同时获得分类与检测结果。页面展示原图、带框结果、宿主、四大属性、具体类别、分类置信度、Top-5 和检测明细。`docs/screenshots/desktop-analysis.png` 展示了真实害虫图片的带框输出；移动端截图验证了窄屏下的布局可用性。

## 5. 实验环境与过程

### 5.1 实验环境

| 项目 | 配置 |
|---|---|
| 操作系统 | Linux |
| Python | 3.12 |
| 深度学习框架 | PyTorch 2.11.0+cu128 |
| 视觉库 | torchvision 0.26.0+cu128 |
| GPU | RTX 4070 Laptop，约 8 GiB 显存 |
| 训练策略 | AdamW、固定随机种子、分类 AMP FP16、检测 FP32 |
| 输入尺寸 | RGB `224 x 224` |

### 5.2 实验步骤

1. 审计 DLCPD-25 的 203 类目录，计算图片哈希并按重复组隔离固定 train/val/test；
2. 读取 IP102 VOC XML，过滤退化框，建立 97 源标签到 96 个检测类及 DLCPD-25 公共 ID 的映射；
3. 以 ImageNet V2 预训练 ResNet-50 为起点，在 DLCPD-25 上分别完成普通交叉熵和类别加权交叉熵的 25 轮分类训练；类别加权模型的最佳验证 checkpoint 位于第 21 轮，并被选为后续初始化权重；
4. 在 DLCPD-25 train/val 上继续训练 5 轮，将分类模型适配为统一的 `224 x 224` 整图直缩预处理；
5. 使用 DLCPD-25 与 IP102 的独立 DataLoader 按 `1:1` 交替训练 10 轮；
6. 每轮仅在两个验证集上报告指标，先检查分类 Top-1 门槛，再按检测 mAP@0.5:0.95 选取最佳权重；
7. 冻结 checkpoint、预处理、标签映射、阈值和 NMS 后，各测试集仅评估一次；
8. 将唯一联合模型包接入 Gradio，测试 CPU/CUDA、异常图片、无框、多框、低置信度和移动页面。

## 6. 实验结果与分析

### 6.1 最终测试结果

| 数据集与任务 | 指标 | 结果 |
|---|---|---:|
| DLCPD-25 分类（22,178 张） | Top-1 | 91.3157% |
| DLCPD-25 分类 | Top-5 | 96.4289% |
| DLCPD-25 分类 | Macro-F1 | 75.4451% |
| DLCPD-25 分类 | Balanced Accuracy | 74.6621% |
| IP102 检测（3,798 张，4,444 个目标） | mAP@0.5:0.95 | 35.8823% |
| IP102 检测 | AP50 | 65.5326% |
| IP102 检测 | Precision | 68.9095% |
| IP102 检测 | Recall | 80.1980% |
| IP102 检测 | Small AP | 6.1139% |

分类 Top-1 高于 91%，说明联合训练后分类能力得到保留。Macro-F1 和 Balanced Accuracy 低于 Top-1，反映长尾类别和相似类别仍较困难。检测 AP50 明显高于 mAP@0.5:0.95，说明在较严格的定位阈值下框的位置精度仍有提升空间。

小目标 AP 仅为 6.1139%。主要原因是 IP102 中的昆虫目标本身较小，统一直缩到 `224 x 224` 后细节进一步减少。该尺寸是根据 8 GiB 显存和课程周期作出的工程取舍，保证了共享模型能够完成训练与实时演示，但不是小目标检测的最优分辨率。

IP102 测试集中有 95/96 个检测类具备样本支持，源类 61 对应的一个检测标签在测试集中没有样本，因而不报告该类 AP。分类置信度低于 0.55 的比例为 71.3004%，页面会如实显示不确定提示，不能把低分结果解释为可靠诊断。

### 6.2 页面结果

`docs/screenshots/desktop-home.png` 为桌面端初始页面，`desktop-analysis.png` 为真实图片分析结果，显示害虫框、分类结果与低置信度提示。`mobile-home.png` 和 `mobile-analysis.png` 展示移动端纵向重排后的页面。页面验证表明，联合推理可以在一次模型调用中同时返回分类与检测结果，且窄屏不出现页面级横向溢出。

## 7. 总结与展望

本项目完成了 DLCPD-25 203 类农产品病虫害与缺陷分类，以及 IP102 96 类害虫检测的联合系统。通过共享 ResNet-50-FPN 主干和 `1:1` 交替训练，系统在一份权重中同时具备整图分类与害虫定位能力，并提供可直接演示的 Web 应用、模型包校验、结果文件和截图资料。

后续可以从以下方向改进：第一，提高检测输入分辨率或采用多尺度训练，改善小目标 AP；第二，为 DLCPD-25 的病害、缺陷和健康类别补充对象级或病斑级标注，使检测范围不局限于害虫；第三，引入类别重采样、难例挖掘或更适合长尾数据的损失函数；第四，在独立田间数据上评估跨场景泛化和不确定性校准；第五，完善数据许可证和原始来源追踪后再考虑更广泛的分发与应用。
