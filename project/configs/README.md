# 配置文件

| 文件 | 用途 |
|---|---|
| `app.yaml` | 最终联合分类检测 Web 应用 |
| `train.yaml` | 203 类分类训练基线 |
| `j1.yaml` | 将分类模型适配为统一 `224 x 224` 直缩预处理 |
| `j2.yaml` | 双数据集交替训练与 checkpoint 恢复验证 |
| `j3.yaml` | 10 轮正式联合训练与验证集选优 |
| `j4.yaml` | 冻结测试、指标输出和最终模型包构建 |

路径相对于 `project/` 解析。最终应用模型包位于 `assets/model/`；训练配置引用的原始数据、metadata 和中间产物位于工程目录同级，不随精简作业包重复分发。

正式应用只读取 `app.yaml` 指向的单一联合模型包。训练配置中的 SHA-256 用于拒绝错误的 split、taxonomy、映射或初始化权重。
